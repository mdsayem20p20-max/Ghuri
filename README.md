# Ghuri Store v3 — Self Manage Edition

## What you can manage yourself
Login as admin and open **Admin Panel**:
- Add products
- Edit product name/category
- Increase/decrease sale price
- Set old price to show an offer/discount
- Change stock
- Add/change product image URL
- Delete products
- Change shop logo/name
- Change cover/banner title and text
- Change cover image URL
- Change offer bar text
- Change hotline
- Change bKash number
- Change Nagad number
- Manage order status
- View bKash/Nagad transaction IDs

## Guest checkout
Customers do NOT need an account to order. They can enter:
- Name
- Phone
- Full address
- Payment method
- bKash/Nagad transaction ID when applicable

## Run
npm install
npm start

Open http://localhost:3000

## Notes
The bKash/Nagad fields in this version are for manual payment instructions. For automatic payment confirmation, use the official merchant/payment gateway APIs and credentials. bKash provides merchant and online payment gateway/API options: https://www.bkash.com/en/business
